# Test fixtures

## animatic-tiny.mp4

A genuinely valid, tiny MP4 used as the playable-media fixture for animatic
candidate import and browser playback proofs.

- Generation (deterministic, no external inputs):

  ```
  ffmpeg -f lavfi -i testsrc2=size=64x64:rate=24:duration=1 \
    -pix_fmt yuv420p -movflags +faststart animatic-tiny.mp4
  ```

- Properties: 64x64, 24 fps, 1.0 s, h264/yuv420p, faststart (moov before
  mdat), boxes `ftyp/moov/free/mdat`, 8589 bytes.
- SHA-256: `93cab18e672643e986a59831a0173a3319a05a80adbf2b237e7c9c989fcec1e8`
- Provenance and rights: generated by ffmpeg's built-in `testsrc2` synthetic
  pattern source — no third-party content, no personal data, no licensing
  restrictions beyond ffmpeg's own (LGPL/GPL binaries produce this synthetic
  output freely). Internal test asset; safe to commit and redistribute.
- Why it exists: the earlier `ftyp`-header-only fake bytes were not a real
  movie and could not prove playability. A committed fixture keeps CI
  deterministic and dependency-free while exercising real container parsing
  and browser decoding.
